Installation

Install the package with your package manager of choice:

npm install example-package
Note: callouts use .alert with an optional success, warning or danger modifier.

Basic usage

Import it and call the main function:

import { create } from "example-package";

const app = create({ debug: true });
app.start();

Options

OptionTypeDefaultDescription
debugbooleanfalseLog internal state to the console.
timeoutnumber3000Request timeout in ms.
retriesnumber2How many times to retry.
